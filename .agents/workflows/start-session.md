# Start Session Workflow

<!-- Workflow for beginning an agent session. Usable as a slash command. -->

1. Read `.harness/progress.md` to review the current status and decisions from the last session.
2. Read `.harness/feature_list.json` to inspect active feature states and passing criteria.
3. Review recent changes with `git log -n 5 --oneline`.
4. Run `.harness/init.sh` to initialize dependencies and ensure environment sanity.
5. Pick ONE prioritized task from `.harness/progress.md` or the active feature spec.
