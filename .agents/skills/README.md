# Agent Skills

<!-- Custom domain skills for Antigravity agents. -->

## Structure
- Store each skill in its own dedicated directory: `.agents/skills/<skill_name>/`.
- Each directory must contain a `SKILL.md` file with YAML frontmatter (`name` and `description`).

## Usage Guidelines
- Add skills only for specialized domain knowledge or infrequent, complex workflows.
- Keep general rules and frequent conventions in `.agents/rules/` rather than skills.
